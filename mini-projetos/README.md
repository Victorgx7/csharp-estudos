# Mini-projetos em C#

Nesta pasta vou guardar projetos pequenos que faço para praticar C# e testar o que aprendi.

## Como organizar

Cada mini-projeto deve ter sua própria pasta, com um nome curto que explique a ideia. Por exemplo:

```text
mini-projetos/
├── README.md
├── calculadora-console/
├── conversor-temperatura/
└── lista-de-tarefas/
```

Esses nomes são apenas exemplos de organização; as pastas serão criadas quando os projetos existirem de verdade.

## O que colocar em cada projeto

- Os arquivos de código e, quando aplicável, o arquivo de projeto `.csproj`.
- Um README curto explicando o objetivo, o que pratiquei e como executar.
- Outros arquivos necessários para o funcionamento do projeto.

Projetos independentes devem ficar separados. Se um projeto precisar de vários arquivos, mantenha todos dentro da pasta dele.

## Registro dos estudos

Vou adicionar os mini-projetos conforme eu os desenvolver. Esta pasta não representa uma lista de projetos já concluídos.
