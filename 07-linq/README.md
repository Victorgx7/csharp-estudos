# 07 — LINQ

Espaço para exercícios de LINQ (Language Integrated Query) em C#.

## Assuntos
- Filtrar dados com `Where`
- Projetar resultados com `Select`
- Ordenar com `OrderBy` e `OrderByDescending`
- Consultas com coleções
- Operadores como `FirstOrDefault`, `Any` e `Count`

Comece com exemplos pequenos e registre o que cada consulta faz.
